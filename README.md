# hidane-dev/homebrew-tap

Homebrew formulae for [hidane](https://github.com/hidane-dev/hidane), a Firestore emulator without
Java.

```sh
brew install hidane-dev/tap/hidane
```

`Formula/hidane.rb` is generated for each release by hidane's release workflow
(`packaging/homebrew/formula.mjs`). It installs the release archive for macOS (arm64, x86_64) or
Linux (arm64, x86_64), checked against its SHA-256.
